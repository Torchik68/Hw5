Цей проєкт демонструє використання інструментів bbot з конфігом з API ключами для  для пошуків сабдоменів та Leakos, платформами: cloud.projectdiscovery, trickest

Завдання 1

Було використано інструмент Bbot для пошуку сабдоменів які містять `jira`  в назві сабдомену:
Приклад:
sofia-jira-test.amn.nasa.gov
sofia-jira.amn.nasa.gov
sofia-jira.jpl.nasa.gov
sofia-jira-test.larc.nasa.gov
jira1.jpl.nasa.gov

Використано такі провайдери для конфіга з API ключами
Chaos Project → https://chaos.projectdiscovery.io
OTX → https://otx.alienvault.com
URLScan.io → https://urlscan.io/user/signup/
CertSpotter → https://sslmate.com/certspotter/
IntelX → https://intelx.io/signup

Завдання 2 
Зареєструвався на платформі https://cloud.projectdiscovery.io/ 
Використовуючи функціонал technology сформував список сабдоменів які використовуют Drupal CMS "Drupal", чомусь не надавло доступ та пропонувала перейти на платну версію навіть для завантаження у RAW, але в все ж таки завантажило частину списку

Завдання 3 
Ознайомився з платформою trickest (зареєструватися та отримати безкоштовний акаунт) https://trickest.io/, створив свій простенький workflow для пошуку сабдоменів та іх фільтрації
